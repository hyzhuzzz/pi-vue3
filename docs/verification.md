- 真实 SSE 事件序号连续，任务只产生一次完成终态，流正常关闭。
- 工具执行中取消后，可继续同一会话并保留先前上下文。
- 在首次任务执行工具时强制结束测试进程，重启后任务显示为中断；下一轮仍可恢复首次输入的标识。
- 构建后的 Node 服务实际返回前端页面与静态资源，页面无运行时错误，窄屏无横向溢出。
- 桌面、展开模式和移动端截图来自实际模型回复与工具调用界面。

真实模型检查由 `pnpm test:live` 单独执行，不属于默认测试或 CI。其他兼容模型可使用同一检查验证接入情况。

## 当前边界

当前实现为可信单用户、单进程和本地文件存储。认证、多用户隔离、MCP 客户端及用量治理由应用继续扩展。持久化文件目前采用基础结构校验，不提供手工编辑、损坏文件自动修复或数据库迁移工具。
